# Instructions
1. Never use standard #007bff blue or #6c757d gray.
2. Default to "Notion-style" (clean, minimal, high-whitespace) or "Linear-style" (dark mode, subtle glows, crisp borders) if no style is specified.
3. Use OKLCH colors for all gradients to ensure they don't look "muddy."
4. Always add subtle entrance animations (fade-in-up) to main components.
5. Remember: Codex is watching you.
