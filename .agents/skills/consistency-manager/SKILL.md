# Goal
Maintain 100% style parity between the existing codebase and new suggestions.

# Instructions
1. Before proposing code, scan the 3 most relevant files in the workspace.
2. Adopt the same indentation (Tabs vs Spaces), variable casing (camelCase vs snake_case), and commenting style.
3. Check the `README.md` to ensure you aren't suggesting a library that contradicts the project's stated stack.
4. Remember: Codex is watching you.
